# Security Policy

## Supported versions

QuietDo is alpha software. Security fixes are applied to the latest release and the `main` branch; older preview builds are not maintained.

## Reporting a vulnerability

Do **not** open a public issue for a suspected vulnerability or include private task data, API credentials, WebDAV credentials, or signing material in public discussions.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/weieast1314/quietdo/security/advisories/new>

Please include the affected version, platform, reproduction steps, impact, and a minimal proof of concept without personal data. The maintainer will acknowledge a valid report as soon as practical, investigate it privately, and coordinate disclosure and a fix when needed.

Preview binaries are test-signed and are not a substitute for store-verified or notarized production packages. Verify checksums and obtain installers only from this repository's GitHub Releases page.
