# Support

- Usage question or reproducible bug: use [GitHub Issues](https://github.com/weieast1314/quietdo/issues/new/choose).
- Feature proposal: open a feature request before starting a large implementation.
- Security issue: follow [SECURITY.md](SECURITY.md); do not create a public issue.

QuietDo is community-maintained alpha software. Support is best-effort and no response-time guarantee is provided.
