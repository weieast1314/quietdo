# Suishi 0.3.0 Preview / 遂事 0.3.0 预览版

This is the first public source release under the Suishi (遂事) name. / 这是改名为“遂事”后的首个公开源码版本。

## Assets / 发行资产

- `Suishi-0.3.0-universal.dmg`: macOS 12+, Apple Silicon and Intel.
- `Suishi-0.3.0-android-arm.apk`: Android 7.0+, ARM64 and ARMv7.
- Matching `.sha256` files can be used to verify transferred assets.

## Important / 重要说明

- The macOS DMG is ad-hoc signed and **not notarized**. It is a preview package, not a production-signed release.
- The Android APK is signed with an Android **test certificate**. It is intended for side-loading and testing, not Google Play.
- Android package identifier: `com.weieast.suishi`; version code: `3000`.
- No physical Android device was connected during this build. APK structure and signature were verified, but final on-device acceptance testing remains open.

- macOS DMG 使用 ad-hoc 签名，**尚未完成 Apple 公证**，不属于正式签名发行版。
- Android APK 使用 Android **测试证书**，只适合侧载测试，不能提交 Google Play。
- Android 包名：`com.weieast.suishi`；versionCode：`3000`。
- 构建时没有连接安卓真机；已验证 APK 结构和签名，但仍需完成真机验收。
