# QuietDo 0.4.0 Alpha / 轻作 0.4.0 Alpha

This is the first public source release under the QuietDo (轻作) name. It focuses on a clean open-source baseline and reproducible multi-platform packaging.

这是使用 QuietDo（轻作）名称的首个公开源码版本，重点是建立清晰的开源基线和可复现的多平台打包流程。

## Highlights / 主要变化

- English and Simplified Chinese READMEs with an explicit feature/status matrix.
- MIT license, contribution guide, security policy, support policy, code of conduct, issue templates, and pull request template.
- CI for Web lint/tests and native TypeScript/Rust checks.
- Manually triggered draft release workflow for macOS, Android, Windows, and Linux preview artifacts.
- Renamed native metadata and package identifier to `com.weieast.quietdo`.
- JSON import remains compatible with exports created under the former Suishi and TaskFlow names.

## Distribution boundary / 发行边界

Preview packages are not store-ready: macOS requires Developer ID signing and notarization; Android requires a long-lived release keystore and AAB for store submission. Windows and Linux packages remain experimental until device acceptance testing is completed.

预览安装包不能直接作为商店正式版本：macOS 仍需 Developer ID 签名和公证，Android 仍需长期保存的发布密钥及 AAB。Windows 与 Linux 在完成真机验收前保持实验性状态。
