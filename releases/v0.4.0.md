# QuietDo 0.4.0 Alpha / 轻作 0.4.0 Alpha

QuietDo is a local-first personal task workspace that turns intentions into clear next actions. This is the first public preview under the QuietDo (轻作) name and the first release with installable artifacts for all four current target platforms.

QuietDo 是一个把意图变成明确下一步的本地优先个人任务工作台。这是更名为 QuietDo（轻作）后的首个公开预览版，也是首次同时提供四个目标平台的可安装产物。

> [!IMPORTANT]
> This is alpha software. Back up important data before upgrading and read the signing notes below. / 这是 Alpha 预览版。升级前请先备份重要数据，并阅读下方签名说明。

## Highlights / 主要变化

- Inbox, Today, projects, areas, smart views, next actions, and completion criteria.
- Offline smart capture for dates, priorities, and `#project`, plus local task review for overdue, stale, vague, or incomplete work.
- Local IndexedDB storage and JSON backup/restore; task management remains available offline and without an AI provider.
- PWA support and a shared Tauri 2 shell for macOS, Android, Windows, and Linux.
- English and Simplified Chinese documentation, MIT license, contribution and security policies, issue templates, CI, and reproducible release automation.
- Native metadata now uses `com.weieast.quietdo`; JSON import remains compatible with former Suishi and TaskFlow exports.

## Upgrade note / 升级说明

QuietDo uses a new native identifier and cannot automatically read the former Suishi preview's data container. In the former app, open the Data dialog and export a JSON backup **before** installing QuietDo, then import that file in QuietDo. Existing QuietDo Web/PWA users should also create a backup before evaluating an alpha build.

QuietDo 使用了新的原生应用标识，无法自动读取旧版“遂事”预览版的数据容器。请先在旧应用的“数据”窗口导出 JSON 备份，**再**安装 QuietDo，然后在 QuietDo 中导入备份。现有 Web/PWA 用户试用 Alpha 版前也建议先备份。

## Signing and platform notes / 签名与平台说明

- **macOS:** ad-hoc signed and not Apple-notarized. Gatekeeper may block the first launch; use Finder's **Open** action only after verifying the checksum and repository source.
- **Windows:** unsigned and may trigger Microsoft Defender SmartScreen. Windows artifacts are not yet device-tested.
- **Android:** signed with a test certificate for side-loading only. It cannot be upgraded into a future store build and is not suitable for Google Play.
- **Linux:** AppImage and DEB are experimental and not yet device-tested across distributions.

- **macOS：** 使用 ad-hoc 签名，尚未经 Apple 公证。Gatekeeper 可能会拦截首次启动；请在校验摘要并确认仓库来源后，使用 Finder 的“打开”操作。
- **Windows：** 未签名，可能触发 Microsoft Defender SmartScreen；尚未完成真机验收。
- **Android：** 只使用测试证书签名，仅适合侧载试用；无法直接升级为未来的商店版，也不能用于 Google Play。
- **Linux：** AppImage 和 DEB 仍为实验性产物，尚未覆盖不同发行版的真机验收。

## Known limits / 已知边界

- AI provider and privacy controls are configuration UI only in 0.4.0; task content is not sent to an LLM.
- WebDAV is configuration UI only; credential storage, synchronization, and encrypted multi-device sync are not implemented yet.
- This release is intended for evaluation, feedback, and local data workflows rather than production or store distribution.
